# 設計決策

暖紙色系：米色紙張的背景、磚紅與葉綠兩個重點色、手寫感的標題字。版面平面、乾淨，用線條分區。（萬事屋阿泰 2026-11-19 定案）

## 配色與字體

| 用途 | 值 |
|---|---|
| 背景（紙） | `#fbf5ec` |
| 淺面 | `#fffdf8`、`#f3ead9` |
| 文字 | `#2e231c`，次要 `#65564b`，更淡 `#9a8a7a` |
| 細線 | `#ead8c4` |
| 主色（磚紅） | `#c2551f`；小字用 `#a9461a`，在紙色上達 4.5:1 |
| 輔色（葉綠） | `#3d7a57`，淺 `#e6f1e6` |
| 標題字 | LXGW WenKai TC（霞鶩文楷）700 |
| 內文字 | Noto Sans TC |
| 編號、標籤 | JetBrains Mono |

## 版面語言

- 平面、無陰影，用細線與粗線分區，圓角最多 3px
- 標題靠左，上方一條粗線，旁邊是編號（01、02…）
- 首頁一條滿版照片帶，每個實驗室一張，點了進該實驗室
- 核心精神做成直列清單
- 直線分區；核心價值用整條葉綠色帶，點子收發室用整條磚紅色帶
- 實驗室用索引列：編號、名稱、主持人、一句話、關鍵字、縮圖
- 文字標籤一律寫全名，不縮成單字

- 首頁：標題區 → 照片帶 → 01 共學實驗室索引 → 02 核心價值 → 03 六個轉化階段與四個條件 → 04 平台怎麼運作 → 點子收發室
- 計畫介紹：左側目錄，右側 12 段全文
